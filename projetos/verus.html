03 · Agenda para Studio de Tatuagem

Agenda Verus

Calendário de sessões, clientes e equipe para um studio de tatuagem e piercing.

O sistema inclui calendário de sessões, ficha do cliente com anamnese, equipe, serviços e um relatório do período.

Em cada sessão é possivel registrar se o sinal foi pago, ficando visível na agenda um aviso que aparece tanto no celular quanto no computador.

Feito com

  • React
  • TypeScript
  • Tailwind CSS
  • Firebase

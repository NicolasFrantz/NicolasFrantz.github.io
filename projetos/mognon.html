02 · CRM para Studio de Tatuagem

Studio Mognon

Agenda e ficha de clientes para um estúdio de tatuagem, com pré-cadastro por link.

A equipe marca a sessão, visualiza o mês e consegue enviar o horário para o Google Agenda ou abrir o WhatsApp com a mensagem pronta.

Cada cliente é cadastrado com uma ficha exclusiva onde a equipe registra a anamnese, briefing e histórico, podendo também gerar um voucher promocional para o cliente.

O cliente preenche o pré-cadastro por um link, respondendo as perguntas personalizadas pelo studio, podendo inclusive incluir campos obrigatórios.

Feito com

  • Vue 3
  • TypeScript
  • Tailwind CSS
  • Firebase
